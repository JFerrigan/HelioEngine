# Vision

This project models civilizations as evolving systems under pressure, not as a player-centric strategy game.

The main premise is:

1. Multiple lifeforms arise from distinct chemistries, such as carbon-based or silicon-based life.
2. Each species develops through an early formative era that shapes its values, survival strategies, and blind spots.
3. Cryo ships or embryo vessels seed new worlds and push those cultures into unfamiliar environments.
4. External pressure - scarcity, radiation, climate, competition, distance, entropy, and time - drives adaptation.
5. The result is a living simulation where civilizations behave like constrained organisms at scale.

The intended tone is hard science fiction. The system should favor plausible constraints over hand-waved magic.

The simulation should support:

- large numbers of agents or civilization objects
- emergent behavior from local rules
- scenario authoring without code changes where possible
- later visual upgrades without changing the simulation model
